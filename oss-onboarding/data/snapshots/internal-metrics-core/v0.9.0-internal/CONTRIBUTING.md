# Contributing to Internal Metrics Core

## Access Authorization
To contribute to Internal Metrics Core, team members must have an explicit, active `MaintainerGrant` verified by an authorized moderator. Contributors without this grant will be blocked at the API gateway with HTTP 403 Forbidden.

## Internal Workflow
1. Request access clearance from the engineering lead.
2. Ensure you are connected to the internal corporate VPN.
3. Work only within feature branches prefixed with `feat/internal-`.
4. Peer review requires two maintainer approvals prior to merge.
