# Contributing to Markdown Docgen

Thank you for contributing to Markdown Docgen! We are a community-driven project and welcome developers of all skill levels.

## How to Get Started

1. **Review Available Issues:**
   - Look for issues tagged `good-first-issue` on our issue tracker.
   - Issues with `status: assigned` are currently worked on by another contributor; choose `status: open` issues.
   - Comment on the issue to let maintainers know you are starting work.

2. **Branching & Commits:**
   - Branch from `main`:
     ```bash
     git checkout -b feat/add-formatter-option
     ```
   - Commit messages should be concise and describe the purpose of the change:
     ```bash
     git commit -m "feat: add markdown table formatter for CLI output"
     ```

3. **Submitting Changes:**
   - Run tests before pushing: `npm test`.
   - Create a pull request to `main`.
   - A maintainer will review your pull request and merge once checks pass.
